## Dev Notes

**O HTML cru é inútil.** O site é um export do Canva: o HTML chega com `<div id="root"></div>` vazio e tudo é desenhado por JS. A fonte de verdade é a **página renderizada no navegador**.

**Fatos já medidos em 17/09** (use como ponto de partida, mas confirme):

| Fato                 | Valor                                                                                                                                                                                         |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Canvas               | 1920 px de largura fixa, 6485 px de altura                                                                                                                                                    |
| Container de rolagem | `div.ZRRuDw` — a página não rola pelo `window`, rola por esse elemento                                                                                                                        |
| Famílias             | `YAFdJkQTgbI` (display serifada: 67/64/58/46/28/25 px) e `YAEnXArs1iQ` (sans: 41/25/24/21/19 px)                                                                                              |
| Paleta               | `#FAF4E9` creme · `#F4F1EC` creme claro · `#F1F1F0` cinza · `#AB93B1` lilás · `#988CA1` roxo · `#FBDB68` amarelo · `#A5B3A1` sage · `#353539` texto · `#222222` texto forte · `#0F1015` preto |

**Truque para rolar a página:** `document.querySelector('.ZRRuDw').scrollTop = N`. Rolar o `window` não funciona.

⚠️ **A captura em 1280 não é um segundo alvo de fidelidade.** Como o canvas é fixo em 1920 px, a captura em 1280 mostra a mesma composição recortada, não um layout alternativo. O alvo de fidelidade é **1920**; entre 1024 e 1920 o layout do rebuild escala proporcionalmente. Não tente reproduzir o recorte de 1280 como se fosse decisão de design.
